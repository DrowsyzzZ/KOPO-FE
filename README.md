# KOPO Frontend 기초

> 프론트엔드 기초부터 React Native까지 실습을 기록하는 저장소입니다.

## About

`src` 폴더에서 실습 코드를 파일 유형별로 관리합니다.<br>
`notes` 폴더에는 강의별 학습 내용과 실습 기록을 정리합니다.

## Repository Structure

```text
KOPO-FE/
├─ src/
│  ├─ html/       # HTML 실습
│  ├─ css/        # CSS 실습
│  ├─ js/         # JavaScript 실습
│  ├─ assets/     # 이미지 및 페이지 썸네일
│  └─ index.html  # 실습 목록
├─ notes/         # 강의별 학습 노트
├─ .gitignore
├─ .prettierrc
└─ README.md
```

## Commit Convention

```text
feat: 새로운 실습 코드 추가
fix: 코드 오류 수정
docs: README 및 학습 기록 수정
refactor: 코드 구조 개선
chore: 프로젝트 설정 및 기타 작업
```
