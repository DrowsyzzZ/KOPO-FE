# 01. HTML 기초

> 웹의 동작 원리를 이해하고 HTML 문서의 기본 구조와 주요 태그를 익히는 강의입니다.

## 학습 내용

### 1. 웹 개발의 기초

- 프론트엔드와 백엔드의 역할
- 웹 페이지가 브라우저에 표시되는 과정
- Chrome DevTools를 활용한 요소 확인
- HTML, CSS, JavaScript의 역할

### 2. HTML 문서 구조

- `<!DOCTYPE html>` 선언
- `<html>`, `<head>`, `<body>`의 역할
- 태그, 요소, 속성의 개념
- 부모 요소와 자식 요소의 관계

### 3. 텍스트와 링크

- 제목과 문단 태그
- `<strong>`과 `<em>`을 이용한 의미 강조
- `<a>` 태그를 이용한 링크 연결
- 절대 경로와 상대 경로

### 4. 시맨틱 페이지 구성

- `<header>`: 페이지의 머리말
- `<nav>`: 주요 메뉴와 탐색 링크
- `<main>`: 핵심 콘텐츠
- `<footer>`: 페이지의 바닥글

## 배운 점

> 강의가 끝난 뒤 직접 이해한 내용을 이곳에 기록합니다.

- 작성 예정

## 더 알아볼 내용

- 시맨틱 태그가 웹 접근성과 검색 엔진에 주는 영향
- 절대 경로와 상대 경로를 선택하는 기준
- 브라우저가 HTML을 해석해 화면을 만드는 과정
