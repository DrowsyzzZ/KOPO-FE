# 02. CSS 기초

> CSS의 기본 문법을 이해하고 선택자와 주요 속성을 사용해 HTML 요소의 스타일을 지정하는 강의입니다.

## 학습 내용

### 1. CSS 적용과 기본 문법

- 인라인 스타일, 내부 스타일시트, 외부 스타일시트
- `<link>` 태그를 이용한 CSS 파일 연결
- 선택자, 속성, 값으로 구성되는 CSS 선언
- 하나의 요소에 여러 스타일 적용

### 2. CSS 선택자

- 태그 선택자, 클래스 선택자, 아이디 선택자
- 전체 선택자와 그룹 선택자
- 자식 선택자와 하위 선택자
- 속성 선택자와 가상 클래스

### 3. 색상, 단위, 텍스트 스타일

- 색상 이름, HEX, RGB를 이용한 색상 표현
- `color`와 `background-color` 속성
- 절대 단위 `px`와 상대 단위 `%`, `em`, `rem`
- 뷰포트 단위 `vw`, `vh`
- 글꼴, 글자 크기, 굵기, 정렬 속성

### 4. 박스 모델

- 콘텐츠 영역의 `width`와 `height`
- 안쪽 여백 `padding`과 바깥 여백 `margin`
- 테두리를 지정하는 `border`
- 크기 계산 방식을 정하는 `box-sizing`
- 모서리와 넘치는 내용을 처리하는 `border-radius`, `overflow`

### 5. 표시 방식과 기타 스타일

- `display` 속성과 `block`, `inline`, `inline-block`의 차이
- 요소의 투명도를 지정하는 `opacity`
- 배경 이미지의 크기와 위치 설정
- 마우스 포인터를 변경하는 `cursor`
- 입력 요소의 외곽선을 지정하는 `outline`
